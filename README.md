# App de Frases

Esta aplicación es una prueba funcional creada para gestionar y visualizar citas de diversos autores y temas. Permite filtrar las frases por autor y tema, y cuenta con una interfaz sencilla para navegar entre las diferentes opciones.

El propósito principal de esta app es mostrar un ejemplo básico de cómo se pueden manejar y presentar datos de manera interactiva.
